# iPad Launcher для Toshiba AT200 (Android 4.0.3)

Легкий лаунчер у стилі iPad: сторінки з іконками, свайп, крапки, док, годинник, пошук.
Без бібліотек, увесь екран малюється одним View, тому працює швидко на слабкому планшеті.
Використовує системні іконки додатків. Мінімальна версія: Android 4.0 (API 14).

## Як отримати APK без встановлення програм на ноутбук

Збірка відбувається на сервері GitHub (безкоштовно). Потрібен лише браузер.

1. Зареєструйся на github.com (безкоштовно).
2. Створи новий репозиторій (кнопка **New**), назва будь-яка, наприклад `ipad-launcher`.
3. Розпакуй цей архів на ноутбуці. У репозиторії натисни **Add file -> Upload files** і перетягни **вміст** папки (разом із папкою `.github`). Натисни **Commit changes**.
   - Якщо папка `.github` не завантажилась: **Add file -> Create new file**, у назві файлу введи `.github/workflows/build.yml` і встав туди вміст файлу `build.yml`.
4. Відкрий вкладку **Actions**. Збірка запуститься сама (1-3 хвилини). Якщо ні: **Build APK -> Run workflow**.
5. Коли з'явиться зелена позначка, відкрий збірку і внизу в розділі **Artifacts** завантаж `iPadLauncher-apk` (це zip з файлом `iPadLauncher.apk`).
6. Якщо збірка червона, відкрий її лог і надішли мені текст помилки.

## Встановлення на планшет

1. На планшеті: **Налаштування -> Безпека -> Невідомі джерела** (увімкнути).
2. Скопіюй `iPadLauncher.apk` на планшет (USB або флешка) і відкрий його через файловий менеджер. Натисни **Встановити**.
3. Натисни кнопку **Home**. З'явиться вибір: **iPad Launcher -> Завжди**.

Повернути стандартний лаунчер: **Налаштування -> Додатки -> iPad Launcher -> Видалити** (або «Очистити налаштування за замовчуванням» у старому лаунчері).

## Керування

- Свайп вліво/вправо: сторінки.
- Дотик до іконки: запуск.
- Довге натискання на іконку: перетягування (змінює порядок, край екрана перемикає сторінку). Відпустити на місці: меню (відкрити, про додаток, видалити, док).
- Перетягнути іконку на док: додати в док.
- Довге натискання на порожнє місце: вибір шпалер.
- Пілюля «Пошук» зверху: пошук за назвою.
- Home: повернення на першу сторінку.

## Збірка вручну

Потрібні JDK 8+ та Android SDK (`ANDROID_HOME`): `bash build.sh`. Результат: `build/iPadLauncher.apk`.
